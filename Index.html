إعداد المزامنة عبر الإنترنت

المزامنة السحابية تحتاج مشروع Firebase خاصاً بالأكاديمية واتصال إنترنت. لا توجد مزامنة فعلية قبل إدخال بيانات المشروع وتفعيل Firestore وAnonymous Authentication. بياناتك الحالية تبقى محفوظة محلياً.

لأمان البيانات: استخدم مشروع Firebase مخصصاً للأكاديمية، وفعّل تسجيل الدخول المجهول وقواعد Firestore المقيدة. لا تشارك مفاتيح المشروع أو صلاحيات قاعدة البيانات مع غير المصرح لهم.
